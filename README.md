# Fältanteckningar

Mobilapp (PWA) för snabba noteringar med datum och klockslag, bild, kort film, automatisk GPS-position och ett redigerbart taggbibliotek.

**Öppna appen:** https://torbra66-ctrl.github.io/faltanteckningar/

## Installera på telefonen
- **iPhone (Safari):** öppna adressen → Dela → *Lägg till på hemskärmen*
- **Android (Chrome):** öppna adressen → meny ⋮ → *Installera app*

Första gången du geotaggar frågar telefonen om appen får använda din plats – svara *Tillåt*.

## Data
Noteringar, bilder och filmer sparas lokalt på telefonen (IndexedDB) – ingenting laddas upp hit.
Använd *Säkerhetskopia* (pilen nedåt) för att exportera allt till en fil då och då.
